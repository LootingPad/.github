# LootingPad

**Fair-launch infrastructure for the open internet.**

LootingPad builds LOOTING — launches, staking, creator fees, and lucky-box rewards with wallet-signed flows. Backend never holds user funds.

🌐 [lootingpad.com](https://lootingpad.com) · 📡 API `api.lootingpad.com`

## Repositories

| Repo | What it is |

| [`main-code`](https://github.com/LootingPad/main-code) | Web app (Explore, Terminal, `/looting`, rewards) |
